시간강사 캡처 자동계산기 PRO v9

이번 버전은 표 전체 한글 OCR에 의존하지 않습니다. 캡처의 가로·세로 표선을 직접 검출한 뒤, 날짜와 맨 아래 계 행을 읽습니다. ‘계’ 숫자를 수업시간으로 사용하고, 점심은 급식비 공제 체크로만 처리합니다. 캡처 이미지는 인식이 끝나면 화면과 메모리에서 자동 삭제됩니다. 따라서 학교 수업확인표처럼 선이 있는 표에 훨씬 안정적으로 작동합니다.

인식이 끝나면 캡처 이미지는 자동 삭제됩니다. 날짜와 수업시간이 정상적으로 읽히면 상태는 자동으로 확인으로 표시됩니다. 점심식사는 급식비 공제용 체크이므로 체크 여부 때문에 ‘확인필요’가 뜨지 않습니다. 수정하면 금액은 즉시 다시 계산됩니다.

② 계산 기준

수업시간 = 캡처의 ‘계’ 행 숫자를 그대로 사용합니다.
주휴수당 = 해당 완성 주의 수업시간 ÷ 40 × 8 × 시간단가
→ 주차별 판단 아래에 실제 숫자를 넣은 계산식도 함께 표시합니다.
단, 근로 시작일을 1주의 시작일로 하여 7일 단위로 보고, 계약기간 평균 주 15시간 이상·개근인 경우 계산합니다.

클립보드 한 번에 인식하는 요령

아래 순서대로 하면 캡처 → 한 번 붙여넣기 → 자동계산 성공률이 가장 높습니다.
  1. 수업확인표를 화면에 크게 표시합니다. 표 전체가 보이도록 하고 너무 작게 축소하지 마세요.
  2. Windows에서 Win + Shift + S 를 눌러 캡처합니다.
  3. 날짜 행부터 맨 아래 ‘점심시간·수업시간·계’ 행까지 포함하고, 표의 왼쪽·오른쪽 테두리도 함께 들어오게 캡처합니다.
  4. 캡처 후 미리보기나 다른 프로그램에 붙이지 말고, 바로 이 계산기로 돌아옵니다.
  5. 파란 ‘클립보드 붙여넣기’ 버튼을 한 번 누릅니다. 브라우저가 클립보드 권한을 물으면 허용을 선택하세요.
  6. 권한창이 뜨지 않거나 버튼이 막히면 계산기 화면 아무 곳에서 Ctrl + V 를 누르면 됩니다.
가장 중요: 캡처 후 ‘사진 미리보기 → 다시 복사’하지 말고, 캡처 직후 원본 클립보드 상태에서 바로 붙여넣기 하세요.
인식이 잘 안 되는 경우: 표를 너무 좁게 잘라 테두리가 빠졌거나, 화면에서 이미 축소된 이미지를 다시 복사한 경우가 많습니다.
